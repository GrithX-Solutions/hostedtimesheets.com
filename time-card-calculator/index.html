Worked time = clock out − clock in − unpaid break

How the Time Card & Timesheet Calculator works

For each workday, subtract clock-in from clock-out, then subtract unpaid break minutes. The calculator applies any selected daily worked-time rounding after the break deduction and adds only valid daily results to the weekly total.

Basic formula

Worked time = Clock out − Clock in − unpaid break

If a shift ends after midnight, this calculator treats it as an overnight shift and continues into the next day.

Example

If you clock in at 9:00 AM, clock out at 5:30 PM, and take a 30-minute unpaid lunch, the calculator returns 8.00 worked hours.

Overtime and pay

You can choose an overtime threshold and multiplier. These settings are configurable because overtime rules differ by employer and jurisdiction. The calculator does not provide legal or payroll advice.

Frequently asked questions

Does the calculator subtract lunch automatically?

No. Enter the unpaid break minutes you want excluded for each day. Do not enter paid break time as an unpaid break.

Can it calculate overnight shifts?

Yes. If clock-out is earlier than clock-in, the calculator assumes the shift ended the following day.

What does decimal hours mean?

Decimal hours express minutes as a fraction of an hour. For example, 8 hours 30 minutes equals 8.50 decimal hours.

Time-card review

Use the calculator to reconcile a weekly punch record

A useful time card lets you trace each daily result back to clock-in, clock-out and break information. Calculate the time first, then review overtime and pay as separate layers.

Check each day's punches before trusting the weekly total

Confirm that every workday has the intended start and end time and that overnight shifts belong to the correct dates. Arithmetic alone cannot reliably solve a missing clock-out or duplicated punch; correct the source record before finalizing the time card.

Break deductions should match the source record

Enter only unpaid break time that separate punches have not already removed. If the time record shows lunch as an off-the-clock gap, subtracting the same lunch again would understate worked time. Review unusual break lengths individually instead of applying one default to every day.

Rounding changes time; overtime classifies time

Daily worked-time rounding is applied after the calculator subtracts the unpaid break from each day’s elapsed shift. Clock-in and clock-out punches are not rounded separately. The overtime threshold then classifies the rounded weekly minutes; neither setting determines what an employer or jurisdiction requires.

Example weekly reconciliation

If five daily rows total 39 hours 50 minutes, the exact decimal equivalent is about 39.8333 hours before any selected rounding convention. If a payroll system shows a different total, compare daily punches, break deductions and the system's rounding policy before assuming one side is wrong.

Invalid rows stay visible and out of totals

If a row has only one punch, equal clock-in and clock-out times, a negative break, or a break longer than the shift, the calculator flags that row and excludes it from weekly totals. A blank row is simply ignored. Blank overtime settings never turn into a zero threshold automatically.

Decimal hours and pay use the same minute source

The calculator keeps exact minute-derived values through the weekly and pay calculations. Decimal-hour displays use up to four places when needed, so minute-based examples such as 481 minutes can display as 8.0167 hours while estimated currency still rounds to cents.

Print and CSV after the review

Use the print or CSV output after you check the entries. The exported result is a convenience copy of what you entered, not a replacement for an employer's approved timekeeping record. For split shifts, use the Weekly Timesheet Calculator; for lunch-specific examples, see the Lunch Break guide.
