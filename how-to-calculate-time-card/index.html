How to Calculate a Time Card

A time card is a day-by-day record of clock-in, clock-out and unpaid break time. Calculate each day first, then total the week.

Use the Time Card Calculator

Quick answer

Subtract clock-in from clock-out for each day, subtract any unpaid break, then add the daily totals for the pay period.

Daily time card = clock out − clock in − unpaid breaks

Methodology: time card calculation workflow

For each workday, record the actual start and end times. Find the elapsed shift, subtract only unpaid breaks, and keep the result in hours and minutes until the daily total is final.

Daily time card = clock out − clock in − unpaid breaks

Worked example

An employee clocks in at 8:12 AM and clocks out at 4:47 PM. The elapsed time is 8 hours 35 minutes. If lunch is 35 unpaid minutes, the day contributes exactly 8 hours to the time card.

Repeat the calculation for every day when schedules vary. This makes missing punches and unusual shifts easier to spot than multiplying one assumed schedule.

How to total the week

Add the net daily values after each break deduction. For example, 8h 00m + 7h 45m + 8h 20m + 8h 10m + 7h 45m equals 40h 00m. Convert to decimals only if the destination system needs them.

Overnight punches

If clock-out is earlier than clock-in, treat the end as the following day. A 9:45 PM to 6:15 AM shift spans 8 hours 30 minutes before break deductions.

Time cards versus payroll rules

A time card records worked time. Overtime eligibility, rounding, paid meal periods and other payroll rules are separate policy decisions. The calculator does not decide which rule applies.

Missing punches

Do not silently guess a missing start or end time. Mark the entry for review and compare it with the source record, schedule or approved correction.

Frequently asked questions

How do I calculate a time card manually?

Calculate each day from clock-in to clock-out, subtract unpaid breaks, then add the daily net totals.

Should I convert to decimals before adding the week?

Keeping exact minutes until the end reduces rounding error. Convert only when the receiving system needs decimals.

Can a time card cross midnight?

Yes. Treat clock-out as occurring on the next day when the shift spans midnight.

Time card workflow

Calculate the punches first, then calculate the week

A reliable time card keeps raw punches, break deductions and calculated hours separate. That makes it easier to find missing punches and explain how the weekly total was produced.

1. Pair each clock-in with the correct clock-out

For a simple shift, subtract the start time from the end time. For split shifts, calculate each in/out pair separately and add the worked segments. Do not count the gap between shifts unless it is recorded as worked time.

2. Subtract only unpaid break time

If lunch is already represented by a clock-out and later clock-in, the gap is already excluded from worked time. Do not subtract the same break again. If the employee remains clocked in through an unpaid break, subtract the approved unpaid minutes once from the elapsed shift.

3. Handle overnight punches explicitly

When clock-out is earlier than clock-in, the end may belong to the next calendar day. A 10:00 PM start and 6:30 AM end is an 8 hour 30 minute elapsed shift before unpaid breaks. Recording the date with each punch is the safest way to avoid ambiguity.

4. Resolve missing or unusual punches before totaling

A blank clock-out, duplicated punch or unexplained long gap should be corrected from an approved source before payroll totals are finalized. A calculator can add valid times, but it cannot know whether a missing punch should have been noon, midnight or something else.

5. Add the net daily values for the weekly total

Keep each day's net worked time in hours and minutes until daily break deductions are complete. Add the days together, then convert to decimal hours only if the payroll or billing system requires decimals. For example, 39 hours 45 minutes is 39.75 decimal hours because 45 ÷ 60 = 0.75.

6. Treat rounding and overtime as separate rules

Time rounding changes recorded time; overtime determines how some hours may be classified or paid. Do not assume a calculator's overtime threshold or rounding choice automatically matches an employer's policy or applicable rules. Verify both settings independently.

Final time card review

Before submitting a card, compare dates, punch pairs, break deductions, daily totals, the weekly total and any manual adjustments with the source record. If pay is being estimated, also verify the hourly rate and any overtime assumptions.
